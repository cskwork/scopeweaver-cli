# scopeweaver-cli v0.1.0

The standalone, agent-native command line edition of ScopeWeaver. Find available packages and checksums on [GitHub Releases](https://github.com/cskwork/scopeweaver-cli/releases). See the [dated verification record](../CLI-VERIFICATION.md) for candidate evidence and publication checks.

- 297 named operations with JSON output, schema discovery, dry-run and confirmation controls. The historical operation ledger establishes one positive contract per exact name, not every option or state.
- A portable CLI and Go engine. PostgreSQL and required Windows runtime files download with pinned checksums on first operational use, then remain in the folder. No separate ScopeWeaver/database installation or system service is required.
- Built-in chat, planner and workers through official Codex CLI 0.162.1: ChatGPT OAuth and Z.AI GLM Coding Plan. Official Codex and the matching login or key are additional requirements; credentials are not bundled.
- Persistent chat controls, queue recovery, side questions, context compaction, findings, traffic evidence, reports and owned local integration workflows. Bounded current-task evidence reaches the first planner request; goal completion still requires actual proof.
- English/Korean landing page and documentation, and EN/KO/zh-Hans command interface summaries.

The 2026-10-18 R24 Windows candidate passed all five unchanged workflows: core **62 calls / 19.14 s**, GLM-5.3/low **106 / 82.63**, Flash/low **117 / 114.84**, ChatGPT OAuth/low **115 / 108.12**, Flash/high **182 / 317.83**. The task budget remained **420 seconds**, shared completion budget **600 seconds**, and all three Z.AI runs recorded zero format corrections. These are functional receipts, not benchmarks or certification of a later artifact. [R24 receipt](../evidence/standalone-cli/candidate-r24-verification.json).

Release package targets are Windows amd64, Linux amd64 and macOS arm64 ZIPs with SHA256SUMS. Native CI snapshots runtime-free packages before first-use testing and retains artifacts only after the job passes. The final clean-head archives, required maintainer review and integration/promotion checks are recorded separately in the [verification record](../CLI-VERIFICATION.md); this document does not assert that a release has been published. Other supported build targets are not certified by this Windows matrix.

Unzip to a writable folder, run `scopeweaver-cli schema --json`, then `scopeweaver-cli health --json` to prepare the runtime. On PowerShell, use `.\scopeweaver-cli.exe`. Stop before moving the whole folder: `scopeweaver-cli runtime stop --yes --json`. Keep private state out of source control.

Known limits: Windows Unicode paths require usable ASCII 8.3 aliases for PostgreSQL; ASCII paths do not. Compaction retains per-call usage without proven inclusion in dashboard aggregates. Owned integration/update fixtures do not prove every live vendor or an upgrade from a previously published GitHub release. Historical failures remain in the [verification record](../CLI-VERIFICATION.md). See [provider setup and limits](../ai-providers.md).
