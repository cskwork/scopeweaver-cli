Unpublished release draft for the standalone, agent-native ScopeWeaver CLI. All five local acceptance workflows passed on the historical R18 candidate; those results do not certify the later R22 four-of-five result. Publication requires native release-package checks and the repository's final human review; this file remains prepared release copy.

- 297 named operations with JSON output, schema discovery, dry-run and confirmation controls. Each operation has at least one positive functional case in the versioned agent-test ledger; this does not cover every option or state.
- A portable folder containing the CLI and engine. PostgreSQL and required Windows runtime files download with pinned checksums on first use, then remain in the folder. No separate ScopeWeaver/database installation or system service is required.
- Built-in chat, planner and workers through official Codex CLI 0.162.1: ChatGPT OAuth and Z.AI GLM Coding Plan. OAuth, GLM-5.3-Flash and GLM-5.3 completed real tool/worker/finding/report workflows in their recorded candidates. Official Codex and the corresponding login or key are additional requirements; credentials are not bundled.
- Durable chat controls, queue recovery, side questions, compaction, reports, traffic evidence and local integration workflows. Earlier shared engine fixes were merged in [ScopeWeaver PR #38](https://github.com/cskwork/scopeweaver/pull/38) on 2026-10-17 at 08:06 UTC. The newer GLM contract/terminal fixes are in [PR #40](https://github.com/cskwork/scopeweaver/pull/40), with its checks and human review tracked separately.
- English/Korean landing page and documentation, with EN/KO/zh-Hans command interface summaries.

Planned artifact targets, subject to native candidate verification: Windows amd64, Linux amd64 and macOS arm64 ZIPs, plus SHA256SUMS. The native CI workflow snapshots runtime-free packages before first-use testing and retains artifacts only after that job passes. Other build targets are not certified for this release.

Unzip to a writable folder, run `scopeweaver-cli schema --json`, then `scopeweaver-cli health --json` to prepare the local runtime. Stop it before moving the complete folder: `scopeweaver-cli runtime stop --yes --json`. Keep private state out of source control.

Known limits: Windows Unicode paths require usable ASCII 8.3 aliases for PostgreSQL; ASCII paths avoid that requirement. Compaction stores per-call usage without proven inclusion in dashboard aggregates. Historical R18 local core, OAuth, GLM-5.3/low and Flash/low/high passed with the unchanged task budget. Historical failures remain in the [verification record](../CLI-VERIFICATION.md). The historical R2–R6 ledger proves at least one positive contract per operation name, not every option/state or final artifact. Integration/update fixtures use owned services and do not prove all live vendors or a previously published GitHub upgrade. See the [provider guide](../ai-providers.md) for setup and limits.
