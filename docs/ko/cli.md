# 독립 실행 구조

[English](../cli.md) · [AI 제공자](ai-providers.md)

한 실행 파일에 공개 CLI와 전용 엔진 런타임이 들어 있습니다. 명령은 인증된 루프백 HTTP로 같은 런타임을 사용합니다. 별도 ScopeWeaver 서버를 설치하지 않습니다. 운영체제 잠금으로 중복 소유자를 막고 클라이언트 종료 뒤에도 작업을 유지합니다. `runtime stop --yes`로 소유한 작업과 데이터베이스를 종료합니다.

공개용 다운로드 방식 폴더에는 CLI·엔진, 기본 스킬, 고지, 고정 소스 정보와 파일 명세가 들어 있습니다. 첫 기능 명령은 고정된 PostgreSQL 압축 파일과 Windows용 Visual C++ 실행 파일을 내려받아 검증한 뒤 엔진을 시작합니다. 실행 파일 옆 `runtime/` 아래에 보관하며 같은 폴더의 여러 홈이 공유합니다. 처음에는 배포 폴더 쓰기 권한과 네트워크 연결이 필요하며 권한 부족·다운로드 실패·체크섬 불일치는 명시적으로 실패합니다. 운영체제 서비스는 등록하지 않습니다. 준비가 끝나면 핵심 기능은 실행 환경을 오프라인으로 재사용하고 클라우드 모델·외부 연동은 각자의 요구 사항을 유지합니다. 명령 탐색과 dry-run은 실행 환경을 내려받지 않습니다.

기본 패키지는 이 첫 실행 경로를 사용합니다. `go run ./packaging -target windows-amd64 -bundle-runtime`은 실행 환경이 미리 들어 있는 로컬 검증용 폴더를 만듭니다. 빌더의 `-offline`은 검증된 다운로드 캐시만 허용하며 런타임의 네트워크 정책이 아닙니다. 실행 환경을 동봉한 검증 폴더는 공개용 산출물과 다릅니다. 체크섬 고정과 로컬 테스트만으로 제3자 실행 파일의 공개 배포 권한이 확보되지는 않습니다.

기본 데이터 위치는 실행 파일 옆 `state/`입니다. `private/`에는 보호된 인증 정보·설정·로그, `postgres/`에는 클러스터, `workspace/`에는 파일·증거가 있습니다. `skills/`는 동봉 스킬을 처음 한 번 복사한 뒤 사용자 수정·삭제를 보존합니다. `--home`별 상태를 분리하고 명시적 전용 설정으로 기존 데이터베이스 설정의 우발적 사용을 막습니다.

이동 전에 종료하세요. 재시작 시 경로와 포트를 다시 계산하며 같은 플랫폼 내 이동을 지원합니다. 실행 중인 클러스터는 복사하면 안 됩니다. 원시 PostgreSQL 디렉터리는 다른 플랫폼의 백업 형식이 아닙니다. 주 버전 불일치나 인증 정보 누락은 데이터를 지우지 않고 실패합니다. 비정상 종료 뒤 남은 데이터베이스는 인증과 데이터 경로 확인 후에만 재사용합니다.

`internal/cli/operations.json`은 이름·경로·입력 형식·영향·응답 형식·근거 위치를 정의하는 실행 계약입니다. 테스트가 고정 경로, 생성된 별도 질문 경로와 채팅 분기를 비교합니다. `schema`도 같은 목록을 사용합니다.

JSON·업로드·다운로드·Markdown·이벤트를 별도로 처리합니다. JSON 한도는 32 MiB입니다. 다운로드는 덮어쓰기를 거부하고 실패한 미완성 파일을 제거합니다. 변경 요청은 자동 재시도하지 않습니다. 스트림은 한 줄에 JSON 이벤트 하나를 출력하고 취소·백엔드 종료 시 끝납니다. 커서 매개변수로 다시 조회할 수 있습니다.

영향은 실제 동작으로 분류합니다. 연동 조회는 외부 서비스를 호출할 수 있고 도구·알림 테스트는 실제 작업을 실행합니다. 조회 이외에는 `--yes`가 필요합니다. `--dry-run`은 런타임 시작·종료나 작업 제출을 하지 않습니다. REPL은 직접 명령과 검증·실행을 공유하며 셸을 실행하지 않습니다. `--data -`는 다음 완전한 JSON 객체를 소비합니다.

오류는 고정 코드·번역된 요약·원본 기술 내용을 표준 오류로, 결과는 표준 출력으로 전달합니다. 명령 이름과 스키마 필드 이름은 고정입니다. 반환된 증거는 신뢰할 수 없는 데이터입니다.

내장 채팅·플래너·워커는 같은 LLM 제공자 생성 경로를 사용합니다. `codex-cli` 형식은 공식 Codex app-server의 표준 입출력을 통해 ChatGPT OAuth 또는 고정된 Z.AI GLM-5.3 Responses 경로를 사용합니다. 새 임시 스레드마다 현재 Norma 대화를 변환하고 구조화 응답 전체를 검증한 뒤 Norma가 요청된 도구를 실행합니다. 스트리밍은 버퍼링하며 Codex의 직접 도구·MCP·플러그인은 비활성화합니다. OAuth는 공식 Codex 로그인·홈과 전역 지침을 상속하고 Z.AI는 깨끗한 임시 홈을 사용합니다. 두 경로 모두 `local_llm_only`가 활성화되면 차단합니다. 공식 Codex는 별도 의존성이며 검증한 버전은 0.162.1뿐입니다. [제공자 설정과 정확한 한계](ai-providers.md)를 확인하세요.

업데이트는 `cskwork/scopeweaver-cli` 배포만 사용하고 체크섬·되돌리기를 유지합니다. 교체 전 정상 실행 경로를 저장해 Linux에서 이름이 바뀐 구버전을 재실행하지 않습니다. 데이터베이스 주 버전과 사용자 수정 스킬은 보존합니다.

이 저장소는 ScopeWeaver `2df0b307dcb817a459abebd3a4c240a2019598db`에서 파생됐으며 Go 모듈은 `github.com/cskwork/scopeweaver-cli`입니다. 추적용 원본 소스·테스트를 보존하지만 배포 실행은 옆의 원본 저장소를 읽지 않습니다. 고정 런타임 해시와 라이선스 고지를 동봉하며 기본 패키지는 첫 실행 때 실행 파일을 내려받습니다. 검증 플랫폼과 한계는 [검증 기록](CLI-VERIFICATION.md)을 확인하세요.
