# scopeweaver-cli v0.1.0 — 릴리스 초안

**공개 보류(2026-10-17).** R22의 포터블 코어, GLM-5.3/low, GLM-5.3-Flash/low, ChatGPT OAuth/low는 통과했습니다. Flash/high는 기존 작업 제한 420초를 초과해 전체 5개 중 4개 흐름이 통과했습니다. AI 실행 4개 모두 실제 도구를 실행했으며 인자 형식 보정은 0회였습니다. 남은 수정, 전체 통과, 네이티브 배포 패키지 검사와 최종 사람 검토가 필요합니다. 공개 배포판은 없습니다. [날짜별 검증 기록](../CLI-VERIFICATION.md)을 확인하세요.

독립 실행·에이전트용 ScopeWeaver CLI의 미공개 릴리스 초안입니다. 과거 R18 후보의 로컬 검증 5개 흐름은 모두 통과했으며 이후 R22 후보의 전체 통과를 뜻하지 않습니다. 공개에는 네이티브 배포 패키지 검사와 저장소의 최종 사람 검토가 필요하며 이 문서는 릴리스 문구 초안입니다.

- JSON 출력, 스키마 조회, dry-run, 확인 절차를 제공하는 명령 297개입니다. 버전별 에이전트 검증 기록에서 각 명령의 정상 동작을 한 가지 이상 확인했으며, 모든 옵션·상태를 검증했다는 뜻은 아닙니다.
- CLI와 엔진을 담은 휴대형 폴더입니다. 첫 실행 때 PostgreSQL과 필요한 Windows 실행 환경을 고정 체크섬으로 검증해 내려받고 폴더 안에 보관합니다. 별도 ScopeWeaver·DB 설치나 시스템 서비스 등록은 필요하지 않습니다.
- 공식 Codex CLI 0.162.1을 통해 내장 채팅·플래너·워커에서 ChatGPT OAuth와 Z.AI GLM Coding Plan을 사용합니다. OAuth, GLM-5.3-Flash, GLM-5.3은 각 기록된 후보에서 실제 도구·워커·발견 사항·보고서 흐름을 완료했습니다. 공식 Codex와 해당 로그인 또는 키는 별도로 필요하며 인증 정보는 동봉하지 않습니다.
- 영속 채팅 제어, 대기열 복구, 곁질문, 컨텍스트 압축, 보고서, 트래픽 증거, 로컬 연동 흐름을 제공합니다. 이전 공통 엔진 수정은 2026-10-17 08:06 UTC에 [ScopeWeaver PR #38](https://github.com/cskwork/scopeweaver/pull/38)로 병합됐습니다. 이후 GLM 계약·종료 처리 수정은 [PR #40](https://github.com/cskwork/scopeweaver/pull/40)에 있으며 필수 검사와 사람 검토는 해당 PR에서 별도로 확인합니다.
- 영어·한국어 랜딩 페이지와 문서, 영어·한국어·중국어 간체 명령 인터페이스 요약을 제공합니다.

검증 대상으로 준비하는 산출물은 Windows amd64, Linux amd64, macOS arm64 ZIP과 SHA256SUMS입니다. 네이티브 CI는 첫 실행 검사 전에 실행 환경이 동봉되지 않은 패키지를 보관하고, 해당 작업이 통과한 경우에만 산출물을 유지합니다. 그 밖의 빌드 대상은 이번 릴리스의 검증 대상이 아닙니다.

쓰기 가능한 폴더에 압축을 풀고 `scopeweaver-cli schema --json`으로 명령을 확인한 뒤 `scopeweaver-cli health --json`으로 로컬 실행 환경을 준비하세요. 폴더 전체를 옮기기 전에는 `scopeweaver-cli runtime stop --yes --json`으로 중지해야 합니다. 비공개 상태 파일은 소스 관리에 넣지 마세요.

알려진 한계: Windows 유니코드 경로에는 PostgreSQL이 사용할 ASCII 8.3 별칭이 필요하며 ASCII 경로에는 이 조건이 없습니다. 압축의 호출별 사용량은 저장되지만 대시보드 합계 반영까지 입증하지는 않았습니다. 과거 R18 로컬 코어, OAuth, GLM-5.3/low, Flash/low·high는 작업 제한을 바꾸지 않고 통과했습니다. 과거 실패는 [검증 기록](../CLI-VERIFICATION.md)에 보존합니다. 과거 R2–R6 누적 기록은 명령명별 정상 계약 하나 이상을 확인한 것이며 모든 옵션·상태나 최종 산출물까지 검증하지는 않습니다. 연동·업데이트 픽스처는 소유 서비스를 사용하므로 모든 실제 공급사나 기존 공개 GitHub 업그레이드를 증명하지 않습니다. 설정과 한계는 [제공자 안내](../ai-providers.md)를 확인하세요.
