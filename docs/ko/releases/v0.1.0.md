# scopeweaver-cli v0.1.0

독립 실행·에이전트용 ScopeWeaver CLI입니다. 패키지와 체크섬의 제공 여부는 [GitHub Releases](https://github.com/cskwork/scopeweaver-cli/releases)에서 확인하세요. 후보 검증과 공개 전 검사는 [날짜별 검증 기록](../CLI-VERIFICATION.md)에 구분합니다.

- JSON 출력, 스키마 조회, dry-run, 확인 절차를 제공하는 명령 297개입니다. 과거 명령 기록은 정확한 명령명별 정상 계약 하나 이상을 확인하며 모든 옵션·상태를 검증하지는 않습니다.
- CLI와 Go 엔진을 담은 휴대형 폴더입니다. 첫 기능 실행 때 PostgreSQL과 필요한 Windows 실행 환경을 고정 체크섬으로 검증해 내려받고 폴더 안에 보관합니다. 별도 ScopeWeaver·데이터베이스 설치나 시스템 서비스 등록은 필요하지 않습니다.
- 공식 Codex CLI 0.162.1을 통해 내장 채팅·플래너·워커에서 ChatGPT OAuth와 Z.AI GLM Coding Plan을 사용합니다. 공식 Codex와 해당 로그인 또는 키는 별도로 필요하며 인증 정보는 동봉하지 않습니다.
- 영속 채팅 제어, 대기열 복구, 곁질문, 문맥 압축, 발견 사항, 트래픽 증거, 보고서와 소유한 로컬 연동 흐름을 제공합니다. 제한된 현재 작업 근거를 첫 플래너 요청에 전달하며 목표 완료에는 실제 증명이 계속 필요합니다.
- 영어·한국어 랜딩 페이지와 문서, 영어·한국어·중국어 간체 명령 인터페이스 요약을 제공합니다.

2026-10-18 R24 Windows 후보는 변경하지 않은 흐름 5개를 모두 통과했습니다. 코어 **62회 / 19.14초**, GLM-5.3/low **106 / 82.63**, Flash/low **117 / 114.84**, ChatGPT OAuth/low **115 / 108.12**, Flash/high **182 / 317.83**입니다. 작업 제한 **420초**, 모델 요청 공유 제한 **600초**를 유지했고 Z.AI 실행 3개의 형식 보정은 모두 0회였습니다. 기능 검증 기록이며 성능 비교나 이후 산출물의 검증은 아닙니다. [R24 기록](../../evidence/standalone-cli/candidate-r24-verification.json).

배포 패키지 대상은 Windows amd64·Linux amd64·macOS arm64 ZIP과 SHA256SUMS입니다. 네이티브 CI는 첫 실행 검사 전에 실행 환경이 동봉되지 않은 패키지를 보관하며 해당 작업이 통과한 경우에만 산출물을 유지합니다. 최종 커밋의 압축 파일, 필수 유지관리자 검토, 통합·승격 검사는 [검증 기록](../CLI-VERIFICATION.md)에서 별도로 확인하며 이 문서는 릴리스 게시 완료를 주장하지 않습니다. 그 밖의 빌드 대상은 이 Windows 검증으로 인증하지 않습니다.

쓰기 가능한 폴더에 압축을 풀고 `scopeweaver-cli schema --json`으로 명령을 확인한 뒤 `scopeweaver-cli health --json`으로 실행 환경을 준비하세요. PowerShell에서는 `.\scopeweaver-cli.exe`를 사용합니다. 폴더 전체를 옮기기 전에는 `scopeweaver-cli runtime stop --yes --json`으로 중지해야 합니다. 비공개 상태 파일은 소스 관리에 넣지 마세요.

알려진 한계: Windows 유니코드 경로에는 PostgreSQL이 사용할 ASCII 8.3 별칭이 필요하며 ASCII 경로에는 이 조건이 없습니다. 압축의 요청별 사용량은 보존하지만 대시보드 합계 반영은 입증하지 않았습니다. 소유한 연동·업데이트 테스트는 모든 실제 공급사나 기존 공개 GitHub 릴리스에서의 업그레이드를 입증하지 않습니다. 과거 실패는 [검증 기록](../CLI-VERIFICATION.md)에 보존합니다. [제공자 설정과 한계](../ai-providers.md)를 확인하세요.
