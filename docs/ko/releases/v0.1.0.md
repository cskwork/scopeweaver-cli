# scopeweaver-cli v0.1.0 — 릴리스 초안

독립 실행·에이전트용 ScopeWeaver CLI의 첫 공개 마이너 릴리스 후보입니다. 이 문서는 릴리스 문구 초안입니다. R7 Flash 검증이 미해결이며 최종 HEAD CI와 저장소에서 요구하는 사람 검토도 남아 있어 공개를 보류합니다.

- JSON 출력, 스키마 조회, dry-run, 확인 절차를 제공하는 명령 297개입니다. 버전별 에이전트 검증 기록에서 각 명령의 정상 동작을 한 가지 이상 확인했으며, 모든 옵션·상태를 검증했다는 뜻은 아닙니다.
- CLI와 엔진을 담은 휴대형 폴더입니다. 첫 실행 때 PostgreSQL과 필요한 Windows 실행 환경을 고정 체크섬으로 검증해 내려받고 폴더 안에 보관합니다. 별도 ScopeWeaver·DB 설치나 시스템 서비스 등록은 필요하지 않습니다.
- 공식 Codex CLI 0.162.1을 통해 내장 채팅·플래너·워커에서 ChatGPT OAuth와 Z.AI GLM Coding Plan을 사용합니다. OAuth, GLM-5.3-Flash, GLM-5.3은 각 기록된 후보에서 실제 도구·워커·발견 사항·보고서 흐름을 완료했습니다. 공식 Codex와 해당 로그인 또는 키는 별도로 필요하며 인증 정보는 동봉하지 않습니다.
- 영속 채팅 제어, 대기열 복구, 곁질문, 컨텍스트 압축, 보고서, 트래픽 증거, 로컬 연동 흐름을 제공합니다. 공통 엔진 수정은 원본에도 [ScopeWeaver PR #38](https://github.com/cskwork/scopeweaver/pull/38)로 제안했습니다.
- 영어·한국어 랜딩 페이지와 문서, 영어·한국어·중국어 간체 명령 인터페이스 요약을 제공합니다.

검증 대상으로 준비하는 산출물은 Windows amd64, Linux amd64, macOS arm64 ZIP과 SHA256SUMS입니다. 네이티브 CI는 첫 실행 검사 전에 실행 환경이 동봉되지 않은 패키지를 보관하고, 해당 작업이 통과한 경우에만 산출물을 유지합니다. 그 밖의 빌드 대상은 이번 릴리스의 검증 대상이 아닙니다.

쓰기 가능한 폴더에 압축을 풀고 `scopeweaver-cli schema --json`으로 명령을 확인한 뒤 `scopeweaver-cli health --json`으로 로컬 실행 환경을 준비하세요. 폴더 전체를 옮기기 전에는 `scopeweaver-cli runtime stop --yes --json`으로 중지해야 합니다. 비공개 상태 파일은 소스 관리에 넣지 마세요.

알려진 한계: Windows의 유니코드 경로에는 PostgreSQL이 사용할 수 있는 ASCII 8.3 별칭이 필요하며, ASCII 경로에는 이 조건이 없습니다. 컨텍스트 압축의 호출별 사용량은 저장되지만 대시보드 합계 반영까지 입증한 것은 아닙니다. 이전 실패 이후 다시 만든 R7 GLM-5.3/low 흐름은 통과했습니다. 형식 보정 시도 0회의 실행이므로 해당 흐름의 통과를 확인한 것이며 새 Z.AI 전용 보정 분기의 실제 복구 성공까지 입증하지는 않습니다. 엄격한 검증은 유지합니다. R7 Flash는 전체 통과로 인정하지 않습니다. low 진단 실행은 발견 사항 2개를 생성했고 high 실행은 변경하지 않은 작업 제한 7분 안에 최종 플래너가 끝나지 않았습니다. 근본 원인은 알 수 없으며 과거 R5 Flash 통과로 이 실패를 해소한 것은 아닙니다. 연동·업데이트 생명주기 픽스처는 소유한 서비스로 검증했으므로 실제 외부 서비스 호환성이나 기존 공개 GitHub 릴리스 업그레이드를 증명하지 않습니다. 정확한 버전과 근거는 [검증 기록](../CLI-VERIFICATION.md)과 [AI 제공자 안내](../ai-providers.md)를 확인하세요.
